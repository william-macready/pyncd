## 1. Goal

A stacked recurrent network whose layer axis `l` is a TENSOR axis (stacked weights `Wp[l, ...]`), with layer `l` at time `t` reading layer `l-1`'s NEW state at the same `t`, cannot be written as a plain scan, but it runs as ONE scan once it is skewed onto the diagonal `k = t + l` with per-step activity masks supplied as data. The 2026-11-24 probe showed this is exact (about 2e-16 against the true model on Lean, JAX eager and JAX jit). Build three fixtures, each in BOTH precisions (a binary64 fixture and a `32` sibling), pinned against independent numpy models of the TRUE (unskewed) model:

1. `rnn_layers_skew`: the skewed stacked RNN with the shift-matrix layer read `Sh[l, m]` and an in-program unskew `Out[l, d, t] := G[l, d, t + l + 1]`.
2. `rnn_layers_native`: the same model with the layer read written natively as `G[l - 1, e, k]` (no `Sh`, no `Out`); out-of-range reads zero-pad, so layer 0 reads zeros.
3. `grid_dp`: a 4x4 grid DP `cell(i, j) = tanh(a cell(i-1, j) + b cell(i, j-1) + c cell(i-1, j-1) + w[i, j])` with zero boundary outside the grid, skewed by `k = i + j`, with the `(i-1, j-1)` dependency (two diagonals back) carried by a delay-line state `D`.

Not in scope (park with a one-line cost if you find more, Rule 14): a native grid or nested scan, any compiler desugaring of the skew, Part V certification, a skew factor above 1 or strided dependencies, variable-length sequences, the out-of-range-read micro-program `Y[l, e] := Z[l - 1, e]` (probed, parked: the native fixture covers it), the mutation manifests, changing any existing fixture, tolerance or pin, `np_transformer`.

## 3. Traps (pre-flight facts; each is respected by the programs below)

1. **Padding rows must be FINITE.** `X` has `k = 8` rows (the iteration extent) but only `T = 5` real ones; rows 5..7 are `0.0`, NOT NaN. The usual NaN spare-row convention of the other fixtures does NOT apply here: `Nn` is computed at every step and multiplied by `Act = 0`, and `0 * NaN = NaN`. Measured in the probe with NaN in X rows 5..7: 24 of 96 entries of `G` NaN, `G[2, :, 7]` non-finite, every input gradient non-finite. So the spare-slot pin of the layers-time slice is replaced by a padding-perturbation pin (section 5). Every input of these fixtures is finite.

2. `Hold = 1 - Act` must be supplied as DATA (no subtraction in a term, no `where` mask over a scan axis, which is refused: `maskAxisNotOutput`).

(Annotation 2026-11-26: `maskAxisNotOutput` no longer refuses a step statement's mask over its own scan axis on Lean; the JAX renderer still refuses a step-aware mask (`axiswiseContextMask`). See `jax_step_mask_scope.md`.)
3. The iteration extent is steps plus one (position 0 holds the initial state): `iter k = 8` gives `step_count` 7 = `T + L - 1` with `T = 5`, `L = 3`.
4. `Ix[k, l, e]` carries the scan axis on its left-hand side: it is a hoisted table and an EXPORT (as in the layers-time `Kn`), not a per-step intermediate.
5. A dependency more than one skewed step back needs one delay-line state per extra step (`D` in `grid_dp`), and the delay-line state must start at the same boundary value as the state (`Gz`): "not started" is read as the zero boundary.
6. All the traps of the layers-time brief section 3 still hold (no subtraction in a term, no state read at `t +1` on a right-hand side, pointwise functions take ONE product, per-step intermediates may not span two scan components, an affine window may be an exact size equation so an index mutant can be REFUSED at prepare: report it and replace it).
7. Extents must be pairwise distinct per program: `rnn_layers_skew`: k=8, l=3, d=4, i=2, t=5 (`e` aliases `d`, `m` aliases `l`); `rnn_layers_native`: k=8, l=3, d=4, i=2; `grid_dp`: k=8, r=4 (`m` aliases `r`).
