## Questions

1. Algebra: yes. `MaxPlus := Tropical (WithBot ℚ)ᵒᵈ`: Mathlib's tropical `+` is `min` of the underlying order, which on the dual is `max` of `WithBot ℚ`; `0` is dual-⊤ = `⊥` (-inf), `1 = trop 0`, `*` is `+`. `MinPlus := Tropical (WithTop ℚ)`: `+` is `min`, `0 = ⊤`. Empirically pinned by `SourceOracleCarrierTest`: max-plus contraction `[101..104]` (max, not min: min would give 2..5), strided odd cells `0` rendering `-inf`; min-plus contraction `[2..5]`, `+inf` fill. The instance is sound (`top_add'` from `WithBot.bot_add`, regularity from `WithBot.add_left_cancel`); the hidden assumption is ℚ cancellativity and that it is global/unscoped (finding 4). `MaxPlus`/`MinPlus` are `def`s with `inferInstanceAs` only for `CommSemiring`/`DecidableEq`/`Repr`, so no instance diamond.
2. No ℚ is hard-wired in the generic path: `Oracle.lean` mentions ℚ only in the `(K : Type := ℚ)` defaults and the `run` docstring. Inputs go through `values.map C.ofRat` (`initialInputs`), accumulators are `0 : K`, products `1 : K` with `*`, sums with `+`. The real path is identical: `Carrier.real = ⟨_, id, .fin⟩`, `values.map id = values`, and `run := runWith Carrier.real`. The hunks of `Oracle.lean` otherwise only add type annotations and the `K` parameter. Not re-verified by `rfl`, and no row asserts `run = runWith Carrier.real` (nit; definitional).
3. `selectCarrier`: first-match is `List.find?`, correct. Empty program picks `(sum, f64)` (finding 6). Mixed aggs (`as, _`) take precedence over mixed element types, so `[(sum,f64),(min,f32)]` reports `mixedSorts` only; no wrong carrier is returned. `[_], ts` is reached only for `ts.length ≥ 2`. `[], _` with a non-empty second component and `[a], []` are unreachable. `Carrier.real.admits = a == .sum` for any element type matches plan line 37 (complex types are rejected earlier by `buildDeclEnv`). No silently wrong carrier with the standard table.
